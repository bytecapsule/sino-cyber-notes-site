美军现役最强的钻地炸弹，重约14吨，从高空投下后能扎进近百米深的土层。但如果碰上的不是泥土，而是莫氏硬度7的火山岩，它大概只能啃进去十几米。

伊朗人把核设施藏在了这种岩石下面。

这座山叫镐山（Kuh-e Kolang Gaz La），位于伊朗中部，距伊斯法罕以北约120千米，紧挨着纳坦兹核设施。2020年，纳坦兹地面设施遭到袭击，离心机组装车间严重受损。离心机是提纯铀的核心设备，靠高速旋转把能做核燃料的铀235从天然铀中筛出来。此后，伊朗开始在镐山地下超过90米深处开挖隧道，准备将核设备转入山体。隧道上方覆盖着超过百米的坚硬岩层，山峰海拔达1600多米，相当于给隧道盖了一面天然盾牌。

这面盾牌的材质叫安山岩，一种火山喷发形成的硬岩石，其间还夹杂着石灰岩条带。安山岩的名字来自安第斯山脉，因为同样的地质机制也在那里造出了大量安山岩。它在莫氏硬度表上排到7，跟石英一个级别，钢钉都划不动它。

但安山岩为什么会出现在伊朗中部的荒漠里？答案藏在几千万年前的一场大陆碰撞中。

地球上曾经有一片古老的海洋，叫新特提斯洋，横亘在阿拉伯板块和欧亚板块之间。随着板块运动，这片海洋的洋壳像传送带一样俯冲到欧亚板块下方。洋壳携带的含水岩石钻到地幔深处，会促使周围岩石熔化，形成岩浆。岩浆向上涌，就在地表堆出一连串火山。这条火山链叫乌鲁米耶-多赫塔尔岩浆弧，镐山就是其中一员。英国牛津大学构造地质学教授理查德·沃克（Richard Walker）曾在该地区做过研究，他说：“这里本质上就是俯冲带上方的火山弧。”

同样的机制，今天还在地球其他地方运转。阿拉斯加的火山群，是太平洋板块俯冲到北美板块下方的产物。南美洲安第斯山脉上星罗棋布的火山，来自纳斯卡板块向南美大陆底下的俯冲。而美国华盛顿州的圣海伦斯火山，背后则是胡安·德富卡板块。

大约3000万年前，新特提斯洋彻底闭合，阿拉伯板块和欧亚板块顶在了一起，俯冲停止，镐山一带的火山也跟着熄灭了。但岩浆冷却后留下的安山岩，至今还硬邦邦地立在那里。

DeCSS破解了DVD上的 CSS 加密。突然间，任何人只需点击按钮就能复制一部电影。这对电影制片厂来说简直是噩梦。

美国电影协会（MPAA）极其愤怒，利用 1998 年刚刚通过的《数字千年版权法》（DMCA），大举起诉、威胁任何传播、托管或链接该代码的网站（包括著名的黑客杂志《2600》和技术社区 Slashdot）。

英国计算机科学家 Phil Carmody 敏锐地意识到，计算机代码在底层就是一串由 0 和 1 组成的二进制数字。他试题通过巧妙的数学公式，把这段“非法代码”打包塞进了一个巨大的质数（素数）里。

使用这个公式：

K×256^N + B

现在，K 是非法代码部分。256^N 是数学上相当于在末尾添加无用零的等价物——就像通过添加空白页来让一本书变长一样。它不会改变里面的实际内容。

Anthropic 反复强调 Opus 5 的一种能力：遇到复杂任务时，它会主动验证自己的结果。一次没有成功，就重新检查、调整方案，再次尝试，直到任务完成。

网络安全部分尤其值得关注。

Anthropic 表示，与 Opus 4.8 一样，没有专门使用网络攻击任务训练 Opus 5。但随着模型综合能力提升，它发现漏洞的水平已经逐渐逼近 Mythos 5。发现漏洞与将漏洞转化为真实攻击工具，仍然存在明显差距。

简言之，Opus 5 已经能够判断一把锁存在什么问题，但距离真正撬开它还有很远。

Anthropic 使用 OSS-Fuzz 评测展示了这种差异。在漏洞发现任务中，Opus 5 与 Mythos 5 接近；到了编写漏洞利用代码的阶段，成绩便明显落后。

基于这一风险边界，Opus 5 会对网络安全请求进行额外审核。一旦请求涉及高风险攻击行为并触发安全限制，系统会将任务回退到 Opus 4.8 处理。

没错，又是 Opus 4.8。

今天起，Opus 5 已在所有平台同步上线。API 模型名称为 claude-opus-5。价格方面，每百万输入 token 为 5 美元，每百万输出 token 为 25 美元，与 Opus 4.8 完全相同。

需要更快响应速度的用户还可以开启 Fast 模式，推理速度约为默认模式的 2.5 倍，价格则提高至两倍。

在 Claude Platform 上，Fast 模式按照基础价格的两倍计费；在 Claude Code 中，则通过使用额度进行抵扣。计费规则与 Opus 4.8 时期保持一致。

伴随模型发布的，还有两个仍处于 beta 阶段的更新。

第一项更新面向 Claude Platform。开发者可以在对话进行过程中，动态修改 Claude 能够使用的工具，同时不会导致 prompt 缓存失效。

第二项更新是 API 自动回落机制。

开发者可以选择将被安全分类器拦截的请求，自动转交给其他模型处理。开启后，请求默认会交给当前可用的最强模型，数据保留方面，Opus 5 延续了以往 Opus 系列的规则，普通访问没有强制数据保留要求。

聪明反被「规矩」误

此次发布中，还有一个颇为反直觉的经验，来自 Anthropic 工程师 Thariq Shihipar。

团队发现，为 Claude 5 系列编写指令时，可以大幅减少系统提示词。Claude Code 的系统提示词被删除了 80% 以上，编程评测成绩却没有出现可测量的下降。

Thariq 随后总结了几条过去被广泛采用、如今可能已经过时的提示词规则。

过去强调给 Claude 制定详细规则，如今更倾向于让 Claude 根据上下文自行判断。例如，旧版系统提示词会明确规定「默认不要编写注释」。面对复杂代码时，这条规则很容易产生问题。

新版本只保留一句要求：生成的代码应当融入周围代码，注释密度、命名方式和整体风格都参考现有项目。

过去强调提供示例，如今更重视接口设计。

Anthropic 发现，示例有时会限制模型的探索范围。相比之下，将工具参数设计得更能准确表达意图，效果反而更好。

过去习惯一次性提供全部信息，如今更提倡按需加载，也就是 progressive disclosure。暂时用不到的代码审查和验证流程，会被放进独立 skill 中，需要时再调用。

过去倾向于反复强调关键要求，如今只要工具说明足够清楚，写一次通常已经足够，没有必要在系统提示词中重复。模型能力提高后，许多原本用于限制错误行为的繁复规则，逐渐变成了新的约束。

Anthropic 还为此推出了一个名为 claude doctor 的命令。用户在 Claude Code 中输入 /doctor，系统便会自动检查过度臃肿的 skill 和 CLAUDE.md 文件，并给出精简建议。

从事无巨细地教模型做事，到逐渐将判断权交给模型，或许才是 Opus 5 此次发布中最值得留意的变化。而当模型越来越聪明，人类写下的那些「经验」，反倒可能成为它首先需要摆脱的包袱。

开放权重与美国人工智能领导力

2026年7月24日

上世纪80年代，早期开源软件先驱挑战了当时盛行的观点：企业只有牢牢掌控代码，软件才能取得发展。这场运动倡导构建透明生态，全球开发者可以研究、修改、改进软件。如今，开源社区开发的软件支撑着互联网绝大部分基础设施，同时也是全球头部科技企业、美军以及联邦科研、网络安全等关键任务机构系统的底层基础。开源的意义远不止降低软件成本；它搭建起共享知识底座，一代又一代美国工程师与创业者依托这一底座建立起技术主权。

如今，美国在人工智能领域面临相似抉择。评判美国AI领导力的标准，不在于是否拥有某一款前沿AI模型，而在于美国能否搭建强大、开放的生态体系，让人工智能渗透各行各业。想要在全美范围内创造创新机遇、实现繁荣发展，就需要扩大人工智能的可及性、鼓励市场竞争、搭建完善的应用层，并让美国人对自身依赖的技术拥有更强掌控力。开放权重模型（任何人都可以下载、查验、修改，并在自有基础设施上运行的AI模型）正是这套体系的重要基石，能够推动先进人工智能技术更加普及、更易适配、广泛可用。

开放权重拓宽人工智能经济的参与门槛。初创企业、成熟公司、高校与公共机构无需从零训练大模型，也不必为每项任务支付前沿模型高昂使用费，就能搭建先进人工智能系统。开放权重能够让各类机构按需匹配合适模型、控制成本：前沿尖端算力专注攻克真正的极限难题，其余场景使用高效的专业化模型。随着人工智能应用拓展至数十亿日常任务，这套资源分配模式将保障AI产业具备经济可持续性。美国想要赢得人工智能时代，就要把人工智能落地到工厂、医院、农场、课堂以及街边实体经济的日常工作流程之中。

开放权重同时能够强化市场竞争；只有充分竞争，人工智能带来的红利才能广泛共享，而非集中在少数主体手中。开放权重允许大量机构自主搭建、调整、部署先进模型，竞争不仅存在于模型研发商之间，也延伸至云平台、芯片、应用程序与各类服务领域。竞争能够激发创新、压低成本，让人工智能的收益遍及全美经济。

开放权重还赋予客户更大自主权。各类机构布局人工智能时，都不希望被单一厂商锁定，或是丢失长期积累形成的技术能力。开放权重模型为此提供保障：机构能够自主管控数据，根据自身需求评估、调整模型，并依据业务需求自由部署。企业依靠人工智能创造价值时，可以依托可自主迭代的模型、定制化能力与持续沉淀的知识掌握价值，夯实美国的技术主权，促进经济繁荣。

当然必须承认，开放权重确实存在独特风险。权重一旦公开发布，就脱离了原始开发者的管控，修改后的衍生版本很难追踪、难以撤回。但应对该风险的正确方式，并不是禁止开放权重。当下网络攻击者已经在利用先进人工智能，网络防御方必须拥有同级别的模型，才能监测、模拟、应对层出不穷的新型威胁。开源模型能够拓宽防御能力边界、提升透明度，便于多方团队共同发现漏洞、修复隐患。

事实上，开放或许是实现人工智能安全保障最重要的路径之一。单纯依靠闭源模型并不天然安全：闭源系统同样会遭遇入侵、遭到滥用，或是出现外部无法察觉的故障。如果少数闭源模型垄断先进AI能力，风险会进一步放大：形成少量单点故障隐患、削弱市场竞争，让关键技术掌握在极少数服务商手里。与之相反，开放权重模型能够让广大研究人员与开发者检验模型行为、识别安全漏洞、设计防护机制并持续优化。正如开源软件证明透明体系安全性能够胜过黑箱模式：想要保障人工智能安全，应当赋予公众测试、完善模型的能力。开放体系支持严谨基准测试、红蓝对抗演练，依据真实可验证的危害制定防护规则，而不是默认闭源系统更加安全。

繁荣的人工智能开放生态不会凭空出现。政策制定者拥有关键行动窗口：为初创团队与科研人员拓展算力获取渠道、投资共享训练资源（数据集、工具、评估框架），审慎监管、避免过早限制开放模型——过度约束会扼杀竞争、迫使创新流向海外。政策制定同时需要研究如何依靠完善的应用生态，推动人工智能在全经济领域自主可控落地。

搭建这套生态体系时，政策制定者应当注意区分合法模型研发手段与非法盗用行为。模型蒸馏技术，即利用一个模型的输出辅助训练、优化另一模型，广泛用于模型改进、评估与验证。这是长久延续下来的技术传统：借鉴现有技术、在其基础上迭代创新，自开源软件浪潮以来持续推动技术进步。与之相对，非法窃取闭源模型价值的行为确实值得重视。这类问题应当依靠针对性法律法规与商业规则解决，不能一刀切限制人工智能创新不可或缺的技术手段。

人工智能时代有望成为繁荣时代。做出正确选择，开放权重人工智能就能拓展机遇、强化竞争优势、巩固美国技术领导力、管控风险，保障这项划时代技术产生的红利在全美经济广泛普惠。这样的未来值得为之建设，美国应当牵头推进。

现代大学里的文科很多都属于Liberal Arts+，而Liberal Arts这个概念自从古希腊时期就有，它包含语法，逻辑，修辞等学科。它们之所以被称为Liberal Arts，不是因为人们通过学习它们，可以获得自由;而是因为只有自由人，才应该去学习它们。什么是自由人呢?自由人就是家境殷实，不需要自己工作挣钱就能生活优渥的人。为什么这些科目被认为只有这样的人才应该去学习呢?因为它们创造不了实际价值，学习它们无法给学习者提供收入可观的工作(留在学校里当讲师除外)，因此如果不是原本家里就有钱，学这些学问很有可能养不活自己。

Scholar+一词则来源于古希腊语中一个意为“闲人”的词语。它和Liberal Arts这个表述一样，都非常明确地指出了文科学习是生存无忧的闲人才应当去从事的事情，若是一个人家境一般，而且想尽量多挣一些钱，那么他不适合学习文科。学一门手艺，也就是前人所说的mechanical arts*里的一种，才是他应当选择的道路。

中世纪时许多学者没有其它谋生的手段，所以只能像江湖骗子(charlatan+)一样四处搭台子讲学。当时的学者都钻研Liberal Arts。后来学者们被招募到一处处固定的场所讲学，这才有了中世纪的大学，也就是现代大学的雏形。这些大学其实最初并不是很高大上，它们的组织形式与中世纪手工业的行业工会类似。Master这个学位名称使用的其实就是裁缝木匠等行业里学满学徒年限，获得独立营业资格的工匠的称谓，而Doctor的本意其实就是教师，意思是获得了这个学位，你就有资格在大学里教课了。

现代的大学教育和文科研究，都是从西方的Liberal education+发展来的，但许多国人却非要把它们和古代的国子监*和科举对标。其实二者内容和功能根本不同，中国的科举考试儒学，儒学是政治学和伦理学，具有实用性。科举选官是选择行政官吏。

现在大学的文科研究，原本就是没有太多实用价值的，所以家境并不富裕的学生，如果看重未来的收入水平，就应避免选择学习文科专业;如果执意选择文科专业，那么他应当做好未来安贫乐道的心理准备。

许多文科知识非常有社会意义，但是绝大多数有社会意义的文科知识应该属于通识课，而非专业研究的范畴。道德，伦理，历史等方面的一些重要概念和基础知识，不仅可以陶冶大众的情操，更是维持社会的公序良俗所必需的。

而正因如此，它们才属于每个人都应该学习与了解的东西。有社会价值的科学知识不需要在社会上广为流通，各个科学领域的专家可以通过自己的专业知识设计造福人类的高科技产品，而人们使用这些产品并不需要掌握它们的复杂原理;但有社会价值的文科知识一定是可以被广泛传播和理解的，因为它们只能通过左右人们的观念来起作用，而只有人们能够理解一些概念时，他们的观念才有可能会被这些概念左右。

但是文科研究到了大学阶段，便越发远离了“广泛传播与理解”这条重要的准则;相反学术圈愈发地通过制造各种学术行话和荒诞的概念，把文科研究变成了少数人的自娱自乐。它对于社会上绝大多数人毫无意义，因此也自然没有什么实际价值。
